# Operator Surface

Primary navigation is intentionally small:

`TODAY | NEEDS REVIEW | CLIENTS | FLIGHTS | MANUFACTURING | EDGE`

## TODAY
Shows due captures, overdue actions, manufacturing handoffs, delivery follow-ups, and appliance alerts.

## NEEDS REVIEW
Exception queue. Every item must state **why it is here**, who owns the next step, and how long it has been waiting.

## CLIENTS
Searchable client index with monitoring cadence, last completed capture, current device version, and open action count.

## FLIGHTS
Human-readable Flight Sheet view backed by canonical timeline events.

## MANUFACTURING
Requirements, design versions, fabrication, QA, delivery, and adjustment loop.

## EDGE
Appliance health and trust controls. Never mix client urgency with generic infrastructure noise.
