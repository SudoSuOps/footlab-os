# FootLabOS Pilot V1

## Goal

Prove that a small cohort can complete consistent longitudinal monitoring with low client effort while FootLabOS creates usable Flight Sheets and closes the loop into manufacturing follow-up.

## Suggested cohort

5–10 consenting pilot clients with clearly defined human oversight and enrollment criteria.

## Pilot rhythm

### Day 0 — enrollment
- identity/contact verification
- consent
- capture training
- baseline capture
- footwear/device inventory
- monitoring cadence
- human escalation contacts

### Days 1–7
- scheduled capture prompts
- completion tracking
- quality/retry rate
- review routing
- Flight Sheet generation

### Weeks 2–4
- continue monitoring
- record material changes and human actions
- create manufacturing requirement when appropriate
- track device version and delivery

### After delivery
- wear check
- comfort/fit feedback
- new capture comparison
- adjustment loop if needed
- continue scheduled monitoring

## V1 metrics

- capture completion rate
- median client session duration
- image retry rate
- time from completed capture to required human review
- number of review events with clear disposition
- Flight Sheet completeness
- manufacturing turnaround time
- device adjustment count and reason
- post-delivery monitoring adherence
- client-reported usability/friction

These are operating metrics, not claims of medical efficacy.
